# Testing

## PHP

```bash
php artisan test
```

Coberturas planejadas: API publica, contato, policies, cache, assistente, tool calls, auth/admin, uploads e filas.

## React

```bash
npm run test:react
```

Coberturas iniciais: terminal whitelist, comandos proibidos e controles de janela.

Meta inicial: 80% para regras de negocio. A meta deve priorizar fluxos criticos em vez de testes artificiais.
